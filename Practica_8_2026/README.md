Sistema de gestión bancaria que demuestra el uso de cuatro estructuras de colección distintas
se implementó búsqueda por tipo de cuenta Y saldo mínimo simultáneamente es importante porque en un banco real necesitas consultas como 
"muéstrame todas las cuentas de ahorro con más de $5,000" para análisis de datos o asi
CCuenta implementa Comparable para ordenarse por saldo y Comparators ordenamiento por nombre y por saldo como criterios externos.

Para este proyecto se necesita un IDE compatible con java 11 o superior, compilar y posteriormente correr Main.java
