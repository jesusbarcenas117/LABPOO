
En esta práctica creé un sistema básico de cuentas bancarias usando Java. El programa tiene 3 clases: Cuenta, Banco y Main.
La clase Cuenta representa una cuenta bancaria con atributos como saldo, nombre, domicilio, edad y deuda. Tiene 3 constructores con diferentes parámetros y 5 métodos para depositar saldo, retirar saldo, agregar deuda, saldar deuda y cambiar domicilio.
La clase Banco contiene una lista de cuentas usando ArrayList y tiene métodos para agregar cuentas, buscar una cuenta por nombre y mostrar todas las cuentas registradas.
La clase Main demuestra la creación y uso de 5 objetos de tipo Cuenta, los agrega al banco y aplica los métodos de instancia para modificar sus datos, mostrando los resultados antes y después de las operaciones.
